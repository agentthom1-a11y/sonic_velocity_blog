STEP 1: LOGIN TO HOSTINGER
□ Go to: https://hpanel.hostinger.com
□ Login with your credentials
□ Select your hosting account

STEP 2: UPLOAD PACKAGE
□ Open File Manager
□ Navigate to: public_html (or your app directory)
□ Click "Upload" button
□ Select: sonicvelo-hostinger-deploy.zip
□ Wait for upload to complete (339.63 MB)
□ Right-click zip file → "Extract"
□ Confirm extraction

STEP 3: CONFIGURE ENVIRONMENT
□ Open SSH Terminal (or use SSH client)
□ Navigate to app directory:
  cd /home/your-username/public_html
  
□ Edit .env.local:
  nano .env.local
  
□ Update these values:
  - NEXT_PUBLIC_SITE_URL=https://yourdomain.com
  - ALLOWED_ORIGIN=https://yourdomain.com
  - ADMIN_PASSWORD=your-secure-password
  
□ Generate new SESSION_SECRET:
  node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
  
□ Paste the generated secret into .env.local
□ Save and exit (Ctrl+X, Y, Enter)

STEP 4: INSTALL & START
□ Install dependencies:
  npm install --production
  
□ Start with PM2 (recommended):
  npm install -g pm2
  pm2 start server.js --name sonicvelo-blog
  pm2 save
  pm2 startup
  
□ OR start normally:
  npm start

□ Verify Node.js version: node --version (need 18+)
□ Check .env.local configuration
□ Restart: pm2 restart sonicvelo-blog

Database errors?
□ Check file exists: ls -la data/cms.db
□ Fix permissions: chmod 644 data/cms.db
□ Check integrity: sqlite3 data/cms.db "PRAGMA integrity_check;"

Can't access admin?

□ Clear browser cache
